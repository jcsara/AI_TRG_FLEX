# Frequently Asked Questions (FAQ)

## General Questions

### What is AI_TRG_FLEX?
AI_TRG_FLEX is a comprehensive training platform for learning AI and machine learning. It provides structured lessons, hands-on exercises, and practical projects to help you develop AI skills.

### Who is this training for?
This training is suitable for:
- Beginners new to AI and machine learning
- Developers wanting to add AI skills
- Data scientists looking to formalize their knowledge
- Anyone interested in learning AI systematically

### Do I need prior programming experience?
Yes, basic Python programming knowledge is recommended. If you're new to Python, we suggest completing a Python basics course first.

### Is this free?
The training materials in this repository are freely available for educational purposes.

## Getting Started

### How do I start?
1. Follow the [setup guide](getting-started/setup.md)
2. Read the [introduction](getting-started/introduction.md)
3. Complete your [first project](getting-started/first-project.md)

At minimum:
- Python 3.8 or later
- NumPy, Pandas, Scikit-learn
- Jupyter Notebook (optional but recommended)

See the [setup guide](getting-started/setup.md) for detailed instructions.

### How long does the training take?
It depends on your pace and prior knowledge:
- Beginner module: 2-3 weeks (10-15 hours)
- Intermediate module: 4-5 weeks (20-25 hours)
- Advanced module: 6-8 weeks (30-40 hours)

## Technical Questions

### What programming language is used?
Primarily Python, as it's the most popular language for AI/ML.

Not for beginner and most intermediate content. A GPU becomes beneficial for:

Main libraries:

- **Scikit-learn**: Machine learning

- **TensorFlow/PyTorch**: Deep learning (advanced)

### Can I use Google Colab?
Yes! Google Colab is great for:

- Pre-installed libraries

## Troubleshooting

### My code doesn't work. What should I do?
1. Read the error message carefully
2. Check the documentation
3. Review similar examples
4. Search for the error online
5. Ask for help in discussions

### The installation failed. Help!
Common issues:
- **Python version**: Ensure Python 3.8+
- **Permissions**: Try `pip install --user`
- **Virtual environment**: Use venv or conda
- **Conflicting packages**: Create a fresh environment

### My model performs poorly. What's wrong?
Check:
- Data quality and preprocessing
- Train/test split
- Feature scaling
- Model choice for the problem
- Hyperparameters
- Overfitting/underfitting

### I don't understand the math. Can I still learn?
Yes! Focus on:
- Intuitive understanding first
- Practical implementation
- When to use what
- Math will make more sense with practice
