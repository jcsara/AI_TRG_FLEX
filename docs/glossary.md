# AI_TRG_FLEX - Glossary

A comprehensive glossary of AI and machine learning terms used throughout the training.

## A

**Accuracy**  
The proportion of correct predictions among all predictions made. Calculated as: (TP + TN) / (TP + TN + FP + FN)

**Activation Function**  
A mathematical function applied to the output of a neuron in a neural network. Common examples: ReLU, sigmoid, tanh.

**Algorithm**  
A step-by-step procedure for solving a problem or completing a task.

**Artificial Intelligence (AI)**  
The simulation of human intelligence by machines, enabling them to perform tasks that typically require human intelligence.

## B

**Backpropagation**  
An algorithm for training neural networks by computing gradients of the loss function with respect to weights.

**Batch**  
A subset of the training dataset used in one iteration of model training.

**Bias (Statistical)**  
Systematic error introduced by making assumptions in the learning algorithm.

**Bias (Neural Network)**  
A learnable parameter in neural networks that allows shifting the activation function.

**Binary Classification**  
A classification task with only two possible output classes.

## C

**Classification**  
A supervised learning task where the goal is to predict discrete class labels.

**Clustering**  
An unsupervised learning task that groups similar data points together.

**Confusion Matrix**  
A table showing the performance of a classification model, displaying true positives, true negatives, false positives, and false negatives.

**Convolutional Neural Network (CNN)**  
A type of neural network designed for processing grid-like data, especially effective for images.

**Cross-Validation**  
A technique for evaluating model performance by splitting data into multiple train/test sets.

## D

**Data Augmentation**  
Techniques to artificially increase the size and diversity of a training dataset.

**Dataset**  
A collection of data used for training, validating, or testing machine learning models.

**Deep Learning**  
A subset of machine learning using neural networks with multiple layers.

**Dimensionality Reduction**  
Techniques to reduce the number of features while preserving important information.

**Dropout**  
A regularization technique where random neurons are ignored during training to prevent overfitting.

## E

**Ensemble Method**  
Combining multiple models to improve overall performance.

**Epoch**  
One complete pass through the entire training dataset.

**Error**  
The difference between predicted and actual values.

## F

**Feature**  
An individual measurable property or characteristic used as input to a model.

**Feature Engineering**  
The process of creating new features or transforming existing ones to improve model performance.

**Feature Scaling**  
Normalizing or standardizing features to a similar range.

**Fine-tuning**  
Adjusting a pre-trained model on a new, related task.

## G

**Generalization**  
The ability of a model to perform well on unseen data.

**Gradient Descent**  
An optimization algorithm that iteratively adjusts model parameters to minimize the loss function.

**Ground Truth**  
The actual, correct values in a dataset.

## H

**Hyperparameter**  
A parameter set before training that controls the learning process (e.g., learning rate, number of layers).

**Hyperparameter Tuning**  
The process of finding optimal hyperparameter values.

## I

**Imbalanced Data**  
A dataset where classes have significantly different numbers of examples.

**Inference**  
Making predictions using a trained model on new data.

## K

**K-Fold Cross-Validation**  
A cross-validation technique that divides data into K subsets, using each as a test set once.

## L

**Label**  
The target or output variable in supervised learning.

**Learning Rate**  
A hyperparameter controlling how much model weights are adjusted during training.

**Loss Function**  
A function measuring the difference between predictions and actual values.

## M

**Machine Learning (ML)**  
A subset of AI focused on algorithms that learn from data.

**Model**  
A mathematical representation learned from data that makes predictions.

**Multi-class Classification**  
Classification with more than two possible output classes.

## N

**Neural Network**  
A computing system inspired by biological neural networks, consisting of interconnected nodes.

**Normalization**  
Scaling features to a specific range, typically [0, 1].

## O

**Overfitting**  
When a model learns training data too well, including noise, and performs poorly on new data.

**Optimizer**  
An algorithm that adjusts model parameters to minimize the loss function.

## P

**Parameter**  
A variable learned by the model during training (e.g., weights, biases).

**Precision**  
The proportion of positive predictions that are actually correct: TP / (TP + FP)

**Principal Component Analysis (PCA)**  
A dimensionality reduction technique that creates uncorrelated features.

## R

**Recall**  
The proportion of actual positives correctly identified: TP / (TP + FN)

**Regularization**  
Techniques to prevent overfitting by adding constraints or penalties to the model.

**Regression**  
A supervised learning task where the goal is to predict continuous values.

**Reinforcement Learning**  
Learning through interaction with an environment using rewards and penalties.

## S

**Standardization**  
Scaling features to have zero mean and unit variance.

**Supervised Learning**  
Learning from labeled data with input-output pairs.

## T

**Test Set**  
Data used to evaluate the final model performance.

**Training Set**  
Data used to train the model.

**Transfer Learning**  
Using a pre-trained model as a starting point for a new task.

## U

**Underfitting**  
When a model is too simple to capture underlying patterns in the data.

**Unsupervised Learning**  
Learning from unlabeled data to discover patterns or structure.

## V

**Validation Set**  
Data used to tune hyperparameters and make decisions during training.

**Variance**  
The model's sensitivity to fluctuations in the training data.

## W

**Weight**  
A learnable parameter that determines the strength of connections in a neural network.
