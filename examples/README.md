# Example Code Repository

This directory contains practical code examples demonstrating various AI and machine learning concepts.

## Available Examples

### 1. Linear Regression
**File**: `linear_regression_example.py`

Demonstrates:
- Simple linear regression
- Data generation
- Model training and evaluation
- Visualization

**Run it**:
```bash
python linear_regression_example.py
```

### 2. Classification Comparison
**File**: `classification_comparison.py`

Demonstrates:
- Multiple classification models
- Model comparison
- Confusion matrices
- Performance evaluation

**Run it**:
```bash
python classification_comparison.py
```

## Requirements

Install required packages:
```bash
pip install numpy pandas scikit-learn matplotlib seaborn
```

## Example Structure

Each example follows this structure:
1. Import necessary libraries
2. Generate or load data
3. Preprocess data
4. Train model(s)
5. Evaluate performance
6. Visualize results

## Adding New Examples

When adding a new example:
1. Follow the existing code structure
2. Include comprehensive comments
3. Add docstrings for functions
4. Include visualization when possible
5. Update this README

## Learning Path

Recommended order:
1. Start with `linear_regression_example.py`
2. Move to `classification_comparison.py`
3. Explore more advanced topics
