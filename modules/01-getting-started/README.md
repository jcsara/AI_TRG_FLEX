# Module 1: Getting Started with AI in FLEX

## Learning Objectives

By the end of this module, you will:
- Understand fundamental AI concepts and terminology
- Set up your FLEX environment for AI development
- Create and run your first AI model
- Understand basic AI workflows in FLEX

## Topics Covered

### 1.1 Introduction to AI
- What is Artificial Intelligence?
- Machine Learning vs. Deep Learning
- Common AI use cases in FLEX

### 1.2 Environment Setup
- Installing required tools and libraries
- Configuring your FLEX workspace
- Verifying your installation

### 1.3 Your First AI Model
- Understanding the problem
- Loading and exploring data
- Training a simple model
- Making predictions

### 1.4 Basic Workflows
- Data input and output
- Model training pipeline
- Evaluation and testing
- Saving and loading models

## Hands-On Exercises

### Exercise 1: Environment Setup
Follow the setup guide to configure your environment and verify all dependencies are installed correctly.

### Exercise 2: Hello World ML Model
Create a simple linear regression model to predict values based on sample data.

### Exercise 3: Classification Task
Build a basic classification model to categorize data into different classes.
